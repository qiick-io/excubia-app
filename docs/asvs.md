# OWASP ASVS 5.0 Level 2 assessment

Reviewed on 2026-11-27 against Excubia App `develop` at `80fb509c` and its locked dependencies. This is a first product assessment against [OWASP ASVS 5.0.0](https://asvs.owasp.org/downloads/), including the cumulative Level 1 and Level 2 requirements.

The scope covers the browser UI, push API, personal keys, MCP, optional OIDC and AI, and the supplied self-hosting image. Deployment-dependent controls cite the shipped setting or operator guide and state what needs confirmation. The assessment uses repository evidence and targeted local browser checks. Live installation controls and external providers require separate verification.
